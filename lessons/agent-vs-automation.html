Automation architecture · Lesson 01

Agent vs. automation

Beginner7 min readChoose the right pattern

In 2 minutes: Traditional automation follows a defined sequence of rules and steps; an AI agent can choose among possible steps based on context and a goal. Predictable, repeatable work is often best handled by a workflow. Ambiguous tasks may benefit from an agent, with bounded tools and review. Many good solutions combine both.

A simple explanation

In a fixed workflow, a known event triggers known actions: validate a form, look up a record, and update a system. This is relatively easy to test when inputs and rules are clear.

An agent can interpret less structured inputs and decide which approved action to try. That flexibility also introduces variability. Compare the task's predictability, risk, exception rate, and need for judgment before choosing. A workflow can call an agent for one contained step; an agent can also ask a workflow to execute a deterministic transaction.

Real-world example

Routing a complete invoice to the right queue using a stable vendor code is a strong workflow candidate. Reading an unusual vendor email and proposing a likely issue category may suit an agent, but a person can confirm the category before a downstream workflow changes records.

Diagram area

A hybrid pattern can keep decisions and execution in the right places:

Request→Agent interprets→Workflow executes

Key takeaways

  • Use fixed automation for stable, rules-based, repeatable steps.
  • Consider an agent where inputs or choices are meaningfully variable.
  • Match autonomy and review to the consequence of a wrong action.

Common mistakes

  • Adding an agent to a process that a simpler workflow already handles well.
  • Comparing only speed and ignoring exceptions, control, and maintenance.
  • Letting flexible interpretation directly trigger high-impact actions without checks.

Practical exercise

Sketch one work task as a sequence. Mark steps with stable inputs and rules as workflow candidates; mark steps involving ambiguous language or judgment as potential agent assistance. Add a person-check wherever an error could cause meaningful harm or cost.
